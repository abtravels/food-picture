# Golden Honey

A program that draws one delicious picture from scratch in pure code: a
wooden honey dipper dripping a thick glossy ribbon of honey into a swirling
pool of honey, warm amber tones on dark slate. One ingredient — honey —
dominates the frame.

Run it with Python 3.13 (Pillow required) and it writes
`/output/entry.png` (1024×1024). No network, no input files, fully
deterministic — every run produces byte-identical output.

```
python3 main.py
```
